# 女娲 V20 交互式页面配置与复现

## 一、案例目标

参考课程实操手册“案例三：待办助理”的页面设计、数据资源绑定、智能体组件绑定和运行验证结构，将配装入口改成表单。用户选择地图与难度、输入预算后直接获得五个风格的完整报告。

[已发布页面：三角洲配装作战台](https://agent.nuwax.com/page/2022659972861952-33302369/prod/)

页面受女娲空间发布范围和访问权限控制，不能仅凭该链接保证所有访客均能使用。页面源码已于2026-10-19导出检查，本目录提供去除平台配置的前端源码参考归档；完整导出包保留在本地。独立运行版本位于仓库 `web/`，迁移详情见 [V21记录](nuwax-export-audit-v21.md)。这些文件不能直接当作 GitHub Pages 静态网页部署。GitHub 的独立技能可按根目录说明本地运行，无需女娲账号。

## 二、页面设计

上部为参数表单，下部为状态、摘要和完整报告。主表单默认“长弓溪谷 / 常规 / 50万”。

| 字段 | 交互与转换 |
| --- | --- |
| 地图 map | 下拉选择，切换后同步可用难度 |
| 难度 difficulty | 仅允许所选地图支持的难度 |
| 整套预算 budget | 输入单位为万哈夫币；正数、最多两位小数；乘10000并取整后传入 |
| 特殊物品 allow_rare | 更多选项，默认false |
| 破损防具 allow_damaged | 更多选项，默认true |

地图难度：零号大坝（常规/机密/永夜）、长弓溪谷（常规/机密）、巴克什（机密/绝密）、航天基地（机密/绝密）、潮汐监狱（绝密）、AZ3（常规/机密）。

常规150万、机密300万、绝密/永夜600万的行动预算上限由核心工作流处理。页面可提示超限，但应传入原始预算，不能在前端擅自改动核心规则。

## 三、数据资源绑定

在页面的数据资源区绑定已发布工作流 `df_搭配_绝密预算V19_1`。复现到自己的空间时，应绑定自己发布的相应工作流，不复制原空间私有接口或凭据。

工作流接收唯一字符串参数 `request_json`，例如：

```json
{
  "request_json": "{\"map\":\"航天基地\",\"difficulty\":\"绝密\",\"budget\":1200000,\"allow_rare\":true,\"allow_damaged\":true}"
}
```

页面通过平台生成的绑定资源调用方式提交，不向聊天窗口拼接指令。按当前页面资源返回结构读取 `success`、`message` 和 `data`；`data` 中包含 `output`、`report_url`、`missing_input`、`map_error`。有错误时显示可读原因；返回报告时嵌入原始完整 `report_url`，同时提供复制和新窗口打开。

不要截断、重新生成或替换 `#r=` 后的报告参数。报告内保留物品图片、枪械配件、改枪码、五风格费用和不可行原因。某一风格预算不足时，仍展示其他风格与完整报告。

生成期间禁用提交按钮，阻止重复调用；结束或失败后恢复。最近五份成功报告仅保存于当前浏览器本机，刷新后可以回看；存储失败不得阻断本次报告显示，不声称跨设备同步。

## 四、智能体配置与发布

1. 完成页面设计与工作流资源绑定，调试正常后发布成页面组件。
2. 在原配装智能体绑定该页面组件，开启“展开页面区”。
3. 使用本目录 `agent_prompt_v20.txt` 的引导约定；开场白提示用户直接填写表单。
4. 页面提交已直接调用工作流，智能体不得再发起重复调用；仍保留用户主动聊天时的配装能力。
5. 发布后使用正式页面验证，而不只检查开发预览。

本次延续 V19 核心规则：绝密猛攻至少五级弹、绝密鼠鼠允许四级弹；金血包、全新防具与金修优先但不强制；花来使用匹配口径的修脚弹；以小博大头甲不超过预算20%且20万封顶；堵桥仅航天基地适用。

## 五、用户操作流程

1. 选择地图与难度，输入整套预算。
2. 按需展开更多选项，设置特殊物品与破损防具。
3. 点击生成，等待价格获取和配装校验完成。
4. 在页面下方查看完整报告；逐风格查看枪弹、装备、补给与费用。
5. 复制完整报告链接、新窗口查看，或从最近记录恢复已生成报告。预算不足时参考缺口建议调整预算后重新生成。
