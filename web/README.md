# 三角洲配装作战台 · 独立版 V21

从女娲 V20 页面导出检查后迁移，保留地图/难度/预算表单、深绿作战板风格、完整报告和最近战报。前端以 HTML/CSS/JavaScript 重写，服务端直接复用仓库 `.agents/skills/delta-loadout` 的 V19 引擎。没有复制一套独立配装规则，无需女娲账号、积分或模型密钥。

## 启动

1. 安装 Node.js 22 或更高版本。
2. 下载并解压整个仓库，必须保留隐藏目录 `.agents`。
3. 在仓库根目录打开终端，执行 `npm start`（无需 `npm install`）。
4. 浏览器打开 **http://127.0.0.1:8787**。关闭服务时按 Ctrl+C。

也可以运行 `node web/server.mjs`。端口被占用时，在 PowerShell 中先执行 `$env:PORT='8788'` 再启动，并使用终端打印的地址。不要直接双击 `index.html`；本页面需要本机 Node.js 服务。

## 使用

- 选择地图和合法难度，输入整套预算（万元，最多两位小数）。超过行动预算上限时由原引擎封顶，并在结果中注明原始预算。
- 更多选项：特殊物品默认不允许、破损防具默认允许。默认抓取最新可用报价；来源异常、过期或覆盖不足时整套回退快照，不混用新旧价格。离线演示可主动选择2026-10-13快照。
- 提交后按钮暂时禁用。五种风格分别核算，某一风格无方案不阻断其他结果；原因可展开查看。
- 完整报告包含枪械配件与改枪码、头甲、胸挂背包、弹药、补给、价格与物品图片链接。无可行方案时显示原因。
- 可以新窗口查看、下载 HTML 或 JSON、复制本机链接。HTML正文离线可读，图片仍需要联网。本机链接只能在运行服务的这台电脑访问；向别人分享请发送下载的 HTML 报告。
- 最近五份报告索引存在当前浏览器，完整结果保存于 `outputs/web/<报告ID>/`。重启服务后文件仍保留；换浏览器不会带走历史索引。删除该输出目录会导致旧链接失效。浏览器存储异常不影响当前结果展示和下载。

独立版使用确定性规则候选，不调用宿主模型选装；女娲版包含模型节点，因此具体物品和总价不要求逐项相同，两者都应通过各自完整规则校验。

## 运行边界

服务只监听 `127.0.0.1`，限制同源访问，未实现公网用户认证。适合个人本机使用，不是开箱即用的多用户托管服务。GitHub Pages 无法执行这里的 Node.js 后端。不要为公网部署直接删除访问限制。

报告由本地引擎生成，不再依赖女娲工作流接口或原 `chatgpt.site` 报告站。动态报价和物品图片仍依赖各自第三方来源。原女娲项目不受本地代码更改影响。

## 文件与验证

`server.mjs` 提供表单 API 与本地报告服务；`worker.mjs` 在独立线程中调用现有引擎；`app.mjs` 负责表单、结果摘要和历史恢复。`index.html` / `style.css` 为无构建步骤的前端。

```sh
npm test
npm run test:web
python scripts/package_skill.py
```

源码 ZIP 包含 `web/` 与课程文档；纯技能 ZIP 维持技能结构。导出原始项目的检查结果见 [迁移记录](../docs/nuwax-export-audit-v21.md)。
